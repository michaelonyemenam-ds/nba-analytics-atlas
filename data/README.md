# NBA Analytics Datasets

This directory contains selected datasets used in the NBA Analytics Atlas.

## Data Categories

- NBA player statistics
- Play-by-play event data
- Shot-level analytics
- Advanced player performance metrics
- Player identity mappings
- Derived statistical features

## Data Processing

Datasets are collected, cleaned, validated, and integrated from multiple sources to support statistical analysis and model development.

## Data Availability

Only datasets permitted for public redistribution will be included.

Large raw datasets, proprietary tracking data, and restricted third-party information will not be published without authorization.

## Project Status

Datasets will be added after source verification and publication review.

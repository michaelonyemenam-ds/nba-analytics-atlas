# NBA Analytics Atlas — Documentation

This directory contains the methodology, metric definitions, and research documentation supporting the NBA Analytics Atlas.

## Documentation Categories

### 1. NBA Badge Atlas
Definitions and classification methods for custom player badges, including:

- Playmaking and offensive creation
- Shooting and shot selection
- Defensive impact and rim protection
- Rebounding and physical activity
- Player roles and archetypes

### 2. Statistical Methodology
Documentation of data cleaning, statistical calculations, percentile rankings, and player comparisons.

### 3. Data Integration
Methods used to combine NBA statistics, play-by-play events, shot-level data, and advanced player metrics.

### 4. Model Validation
Procedures for checking data accuracy, matching player identities, identifying missing observations, and evaluating model performance.

### 5. Research Notes
Exploratory research into basketball decision-making, offensive advantages, defensive positioning, and contextual player performance.

## Project Status

Documentation is being organized for publication. Experimental metrics and classification systems will be clearly identified.

# NBA Analytics Notebooks

This directory contains Jupyter notebooks used for exploratory data analysis, statistical modeling, and visualizations.

## Areas of Analysis

- Player performance and advanced metrics
- Shooting efficiency and expected field goal percentage (xFG)
- Offensive creation and playmaking
- Defensive impact and rim protection
- Player similarity and statistical comparisons
- NBA Badge Atlas exploration

Notebooks will be added as existing analyses are reviewed and organized for publication.

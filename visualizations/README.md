# NBA Analytics Atlas — Visualizations

This directory contains charts, dashboards, and statistical visualizations developed for the NBA Analytics Atlas.

## Visualization Categories

### Player Performance
- Advanced player metric comparisons
- League-wide and positional percentile rankings
- Player similarity visualizations

### Offensive Analytics
- Shot selection and shooting efficiency
- Playmaking and offensive creation
- Expected field goal percentage (xFG)
- Shot location and shot quality

### Defensive Analytics
- Rim protection and shot contesting
- Defensive impact metrics
- Defensive positioning and player roles

### NBA Badge Atlas
- Player badge profiles
- Badge distribution across the league
- Player archetype comparisons

## Tools

Python, pandas, NumPy, and data visualization libraries.

## Project Status

Visualizations will be added as existing analytical outputs are reviewed and prepared for public release.
